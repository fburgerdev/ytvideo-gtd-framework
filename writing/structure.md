# Structure (draft 3)

Set 23-11-2026 in the thread "Video GTD: purpose and goals". Draft 2's script was cleared so draft 3 can start from this structure; it is still in git history (commit fe016e1).

## Purpose

Create curiosity, so viewers try it themselves and realise it for themselves. The video is insightful, like the maths videos, with no doing-good twist.

## Vision

A week later they have copied the file from the description, tried it and are stunned by how much it worked. They begin applying the pattern to meetings and conversations: start with a clear goal and tie everything back to it.

## Common thread

Every step answers to the one above it; skip the top, and everything below is tied to nothing. (Claude's first version was "we're good at the end of thinking and bad at the beginning". Florian's correction, 23-11-2026: it isn't only that the first two steps are skipped, but that the later ones go wrong, because they always connect to the higher steps.)

Jumping to solutions shows the symptoms without naming them: actions nobody can tie to a goal. The five stages names it. The gap explains why the tie gets lost, and All the way up shows the same tie between altitudes: each level's beginning is the level above it.

## Sections (~10 min)

The Outcome of the video and of every section lives in the script (`writing/script/v1.md`, `> Outcome:` lines), so there's one copy to iterate: The file, Jumping to solutions, The five stages, The gap, Off the screen, All the way up, Your turn.
