# Structure (draft 3)

Set 23-11-2026 in the thread "Video GTD: purpose and goals". Draft 2's script was cleared so draft 3 can start from this structure; it is still in git history (commit fe016e1).

## Purpose

Create curiosity, so viewers try it themselves and realise it for themselves. The video is insightful, like the maths videos, with no doing-good twist.

## Vision

A week later they have copied the file from the description, tried it and are stunned by how much it worked. They begin applying the pattern to meetings and conversations: start with a clear goal and tie everything back to it.

## Common thread (Claude's suggestion)

We're good at the end of thinking and bad at the beginning. Chapter 2 shows the symptoms without naming them, chapter 3 names them (purpose and vision are the beginning nobody does), and chapter 4 explains why it goes missing.

## Chapters (~10 min)

| # | Chapter | The viewer leaves it with |
| --- | --- | --- |
| 1 | The file | Curiosity: one file changed everything. What's in it? |
| 2 | Jumping to solutions | Recognition: "I do that too", with AI, in meetings, alone. |
| 3 | The five stages | The method, seen working on something real (this video), and the name for what was missing. |
| 4 | The gap | Why it works: the mind drifts, the supervisor is weak, the file holds the goal. |
| 5 | Off the screen | The pattern without AI: prepare the purpose of a meeting alone, beforehand. |
| 6 | All the way up | A glimpse: the same five steps at every altitude. |
| 7 | Your turn | One concrete thing to try today, with the file in the description. |

## Decided

- Altitudes: a glimpse in chapter 6, the full version as a sequel.
- Chapter 5 uses one real meeting, disguised (topic and setting changed, no names) and told as Florian's own failure. Florian writes it.
- No doing-good twist. Examples may come from his real work, plus an end card to the EA video if that's out first.
